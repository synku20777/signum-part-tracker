# Irmscher Parts Tracker

A personal Opel Signum Irmscher parts tracker. It searches the eBay Browse API,
stores listing and price history in SQLite, scores matches against
`config/parts.yaml`, and can send Telegram alerts.

The supported deployment is one Docker container with one Uvicorn process and a
mounted SQLite database. The tracker never purchases items or contacts sellers.

## Requirements

- Docker Desktop or Docker Engine with Compose
- eBay production Browse API client ID and client secret
- Optional Telegram bot token and chat ID

## First start

Linux/macOS:

```bash
cp .env.example .env
# Add TRACKER_EBAY_CLIENT_ID and TRACKER_EBAY_CLIENT_SECRET to .env
./tracker.sh init
```

Windows PowerShell:

```powershell
Copy-Item .env.example .env
# Add TRACKER_EBAY_CLIENT_ID and TRACKER_EBAY_CLIENT_SECRET to .env
.\tracker.ps1 init
```

`init` builds the image, creates `data/`, generates a random API token only when
the token is blank, starts the container, runs Alembic before the API, and waits
for a healthy response. Existing tokens and databases are preserved.

Open <http://localhost:8000/docs> for the API documentation.

## Configuration

All environment variables use the `TRACKER_` prefix. Important settings are:

| Variable | Default | Purpose |
|---|---|---|
| `TRACKER_API_TOKEN` | generated by `init` | Bearer token for mutating API calls |
| `TRACKER_DATABASE_URL` | `/app/data/tracker.db` | SQLite database URL |
| `TRACKER_EBAY_CLIENT_ID` | empty | eBay Browse API client ID |
| `TRACKER_EBAY_CLIENT_SECRET` | empty | eBay Browse API client secret |
| `TRACKER_EBAY_MARKETPLACE_ID` | `EBAY_DE` | eBay marketplace |
| `TRACKER_TELEGRAM_BOT_TOKEN` | empty | Optional Telegram bot token |
| `TRACKER_TELEGRAM_CHAT_ID` | empty | Optional Telegram destination |
| `TRACKER_SEARCH_INTERVAL_MINUTES` | `30` | Delay between scheduled scans |
| `TRACKER_SCAN_ON_STARTUP` | `true` | Run a scan when the API starts |
| `TRACKER_MAX_CONSECUTIVE_MISSES` | `3` | Complete scans before deactivation |

The API token must contain at least 32 bytes. Secrets, cookies, and `.env` must
not be committed.

## Operations

Both host scripts expose the same commands:

```text
init                  Build, configure, start, and wait for health
start                 Start the service
stop                  Stop the service without deleting data
restart               Restart and wait for health
status                Show Compose service state
logs                  Follow application logs
scan-source ebay      Run an authenticated eBay scan
backup [filename]     Create a consistent backup under data/
restore <filename>    Pre-backup, stop, restore, and restart
doctor                Check database, config, API, eBay, and Telegram state
update                Rebuild, recreate, migrate, and wait for health
```

Examples:

```bash
./tracker.sh scan-source ebay
./tracker.sh backup
./tracker.sh restore backup_20260801_120000.sqlite
./tracker.sh logs
```

Restore accepts a filename directly inside `data/`; nested or external paths are
rejected. It creates a `pre_restore_*.sqlite` backup before modifying the active
database.

## API

- `GET /health` reports database, scheduler, eBay, and Telegram readiness.
- `GET /listings` and `GET /listings/{id}` expose stored listings.
- `GET /matches` exposes the current best match per listing.
- `GET /search-runs` exposes scan history and completion state.
- `POST /runs/ebay` requires `Authorization: Bearer <TRACKER_API_TOKEN>`.

Manual and scheduled eBay scans share one source lock. A concurrent manual scan
returns HTTP 409 with the active search-run ID. Only complete scans increment
listing misses; partial or failed scans preserve lifecycle state.

## Local development

```bash
uv sync
uv run tracker db upgrade
uv run ruff check .
uv run ruff format --check .
uv run mypy src
uv run pytest
docker compose config
```

For local commands, set a development `TRACKER_DATABASE_URL`,
`TRACKER_CONFIG_DIRECTORY`, and a 32-byte `TRACKER_API_TOKEN` in `.env`.

## Troubleshooting

- Container exits during startup: inspect `docker compose logs`; migrations or
  required settings failed before Uvicorn started.
- `/health` returns 503: the database check failed or the scheduler task stopped.
- Scan returns 400: eBay is disabled or its credentials are missing.
- Scan returns 409: another scheduled or manual eBay run is active.
- No Telegram alerts: verify both Telegram values and run
  `docker compose exec irmscher-tracker tracker test-notification`.

Visual matching and non-eBay marketplace adapters are intentionally deferred.
